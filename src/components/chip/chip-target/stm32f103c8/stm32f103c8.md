# STM32F103C8 build support

This is a **retained build-only example**, not an implemented chip simulation or board design. **Cortex-M85 is now the selected demonstration core**; this Cortex-M3 profile does not implement that decision. See [MCU component](../../../../../implementation.md#mcu-component).

1. firmware-support/startup.c performs main-Flash C startup: copy initialized data into SRAM, zero .bss, then call application_main.
2. firmware-support/vectors.c defines the initial MSP and 58 subsequent exception/IRQ slots (59 words total). Function addresses preserve the Thumb bit.
3. firmware-support/linker.ld defines 64 KB Flash at 0x08000000 and 20 KB SRAM at 0x20000000. Initial stack is 0x20005000; .data has a Flash load image and SRAM runtime address.
4. Application main.c/config.h live under components/scripts/default-content/stm32f103c8/. The browser's components/scripts/default-content/profiles.js embeds matching snapshots so the page can open directly.

Select STM32F103C8 under Build target, then use the Arm GCC selector. Verified defaults: Compiler Explorer carmug1320 (GCC 13.2.0); carmug1420/-O2 also passes. Cortex-M3/Thumb/soft-float flags and cross-binutils are applied automatically.

The example writes RAM only. GPIO, LED wiring, clock reconfiguration, RAM boot, libc/C++ constructors, execution and programming are not implemented. The application retains reset clock conditions; it does not call the vendor SystemInit.

Sources: [DS5319](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf), [RM0008](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf), and [ST medium-density startup](https://github.com/STMicroelectronics/cmsis-device-f1/blob/master/Source/Templates/gcc/startup_stm32f103xb.s). The C startup/table are independent minimal code using the documented memory and vector layout; no complete vendor SDK is bundled.
